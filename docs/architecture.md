# 独立工作流与复用边界

```text
素材 + 切片任务 + 源文件绑定的词级 ASR
                  |
          Slicing planner
  选择源范围 -> 定位删除 -> 保留范围 -> 压缩并拼接
                  |
         确定性计划 + 逐项编辑记录
             /                  \
    隔离草稿写入 worker       可选 FFmpeg 渲染
      |                         |
 Auto-Cut Lite primitives       MP4
      |
 可编辑 V1/A1 + 完整本地原素材 + 隐藏原文标签轨
      |
 root / active timeline 结构验收
```

规划器和媒体模块属于新包，没有上游依赖即可测试和编译。草稿 worker 在指定的上游解释器中运行，
使用维护中的 `JyProject` 和源范围可控的 `AudioSegment`；不调用会忽略音频源起点的便利方法。

## 依赖约定

`auto-cut-dependency.lock.json` 锁定 `auto-cut-lite` 源码提交。本机配置不进入 Git。
桥接必须先运行上游 `scripts/assert_lite_workspace.py`，再检查 Git HEAD、源码状态并导入接口。
上游升级应通过独立变更更新锁文件并重跑切片集成测试，不能自动接受版本漂移。

Auto-Cut Lite 的 `review-document-run`、`split_gap` 和时长保留语义不负责本包的真实删除。
新包没有指向其他 Auto-Cut 检出目录的自动回退机制，也不读取上游历史任务缓存。

## 时间模型

所有内部时间为整数微秒，范围为半开区间 `[start,end)`，速度固定为 1。
片段按用户给出的顺序编排。删除和词级匹配都使用原素材坐标，写入草稿时再映射到压缩目标坐标。
每条输出独立计算；删除不改动原始文件。完全空的输出、重叠删除、未知操作和歧义词匹配均拒绝执行。

## 证据边界

计划保存源媒体哈希、源到目标映射和逐条删除记录。草稿包含完整源文件、完整分离音频、逐段同步的 V1/A1、
原文修改标签及结构验收记录。标签不会作为音频删除成功的证据。

未来可以增加接缝试听队列、全候选反向 ASR、字幕裁切重排和多平台竖版布局；这些在实现和实测之前
不属于当前正式能力。源文件哈希绑定的输入 ASR 与完整输出音频反向 ASR 是两种独立证据。
