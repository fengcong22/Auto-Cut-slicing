# 开发与交付验收

开发检查与具体素材的最终验收分别记录。本文件说明覆盖范围，不把合成 ASR 或像素变化视为真实内容验收。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe scripts/smoke_test.py
```

## 规划器与指令

回归检查独立切片、有序拼接、源时间范围、实际删除后的时长和目标映射、源哈希变化、
完整连续词元匹配、重复词歧义、保护词、完全删除、重复 ID、未知字段和未知操作。
语音起点使用 ASR 精确起点；静音保持原时长；定格范围在删除后映射到保留段。
原始多行指令和引号中的语音码点保持原样。保守自然语言解析覆盖参考时间范围、拼接、
源结束、全角标点、语音起点、删词及明确音频删除，未知附加文字会报错。

句边界回归要求源哈希绑定的 utterance 文本与完整词元一一对应，覆盖完整句末、中文/英文标点、
小数点、缩写、省略号、跨 utterance 语句、词内标点、不完整尾句和 ASR 文件哈希变化。
边界取首末词实际时间，不以总体语句时间推测词界。

| 边界场景 | 预期 |
| --- | --- |
| 普通数字起点/终点严格落在句内 | 起点退到句首，终点延至句末。 |
| 句内词尾或停顿 | 补全当前句。 |
| 恰好在句首/句末或句间空隙 | 原坐标不变，不加入相邻句。 |
| 显式语音 cue | 保留唯一完整词元起点，句策略仍补全终点。 |
| 源文件首尾 | 不要求句级证据。 |
| 其他 `sentence` 边界缺少完整证据 | 在输出写入前失败。 |
| 补全令原本不重叠的同源 clips 重叠 | 在输出写入前失败；原本明确重叠仍允许。 |
| 低层 clip 省略策略或声明 `exact` | 保持原范围及旧计划形状，纯范围无需 ASR。 |

句首回退后，显式删除/效果坐标仍为原素材坐标；已 cue 锚定的定格起点继续跟随 cue。
句边界诊断只进入 `boundary_adjustments`，原始 `source_text` 码点保持不变。

## Taskboard MP4 与恢复

真实 FFmpeg 素材检查等比缩放补边、1920×1080 / 25 fps、源音视频同步、静音区间、
定格帧来源、继续播放的音频及累计帧/采样舍入。成片发布前检查视频/音频流、时长和完整解码，
并再次校验源文件；回执保存计划与成片哈希。

批量回归覆盖首条失败后其他输出继续、请求相对路径、输入/输出/结果路径冲突、
拒绝覆盖无关 MP4、结构化片段 ID、JSON/退出码契约和逐步原子结果保存。
恢复检查请求、源文件、计划及已完成成片的哈希、格式、时长与完整解码。
独立 `completion_receipt` 保留原成功证据，暂时无法读取源文件或运行复检时记录当前失败，
恢复条件具备后继续校验同一证据。
策略回归覆盖：新请求默认 `sentence`、顶层 `exact`、clip 覆盖、非法策略、初始 `pending` 即保存策略，
编译失败或进程中断后恢复仍按已保存的默认策略。历史回执缺少策略时按 `exact` 恢复，
旧计划哈希和已完成 MP4 保持兼容；不得仅凭“省略策略”将新失败任务误识别为历史任务。

`inspect-freeze` 使用已解码源帧的时间戳和相邻灰度画面差异提出变化边界候选，
覆盖明确结束边界、变化边界、静止尾段和无效选帧时间。结果始终为 `semantic_verified: false`。
像素变化不能证明“只有 NaOH”或语义上的下一段动画边界，灰度代理也可能漏掉细微、渐变或等亮度变化。
实际交付需检查选中帧和要求的动画/内容边界。

## 可编辑草稿

端到端脚本生成合成视频、正弦波音轨和明确标注的测试 ASR，调用实际 FFmpeg 与已锁定上游的
剪映草稿写入接口。输出在忽略的 `tmp/slicing-smoke-*`，包含素材、任务、草稿、MP4 和报告。

草稿验收包括：删词和段落后的压缩时间轴、指定顺序拼接无声素材、整段移除来源、
完整原始视频与完整分离 WAV、逐段同步的 V1/A1、独立原文标签，以及保存的根草稿和 active timeline
的源/目标范围、时长、素材和编辑回执。MP4 专用效果在草稿入口明确拒绝。

## 实际素材的验收边界

合成素材与测试 ASR 验证实现机制；实际语音服务、接缝试听、完整输出反向 ASR、
所选画面语义、剪映打开及异机打开需要针对真实素材另行验收。
结构测试和完整解码不会把 `spoken_final_acceptance`、`target_open_verified`、
`full_reverse_asr_verified` 或 `semantic_verified` 自动置为 true。
真实切片还需复核句边界证据与末句试听。NaOH 示例的名义终点 220.000 秒位于
“印染等工业”句内，完整末词终点为 220.840 秒；明确“首先”起点 30.510 秒保持，
计划范围应为 `[30.510,220.840)`，时长 190.330 秒，并保留原定格及同期音频。
这是实际素材的核验目标；ASR 句末标点、结构检查和完整解码不构成人工试听验收。
