# 初版开发验收

此文档记录初版开发验证边界，真实项目仍需独立验收。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe scripts/smoke_test.py
```

端到端脚本生成合成视频、正弦波音轨以及明确标记为测试数据的词级 ASR。
它调用实际 FFmpeg 与已锁定上游的真实剪映草稿写入接口，不是模拟草稿结构。
结果保存在忽略的 `tmp/slicing-smoke-*`，包括任务、素材、草稿、导出视频和 `smoke-report.json`。

验证场景：

- 6 秒源视频删除 `[1,2)` 的测试词和 `[3,4)` 的段落，成片 4 秒；
  V1、A1 各有 3 个可编辑片段，分别引用 `[0,1)`、`[2,3)`、`[4,6)`。
- 每个删除项保留一条独立的原文修改标签，包含多行文本时也不改变码点。
- 另一条输出拼接 2 秒无声素材与源视频的 `[4,6)`，保持指定顺序和正确音轨间隙。
- 第三条输出整段移除一个来源，只保留另一个来源的画面；被整段移除的完整视频和音频仍保存在素材库。
- 完整原始视频和完整分离 WAV 保存在草稿本地素材中。
- 保存的根草稿和 active timeline 完全一致，源范围、目标范围、时长、标签和回执通过结构验收。
- 可选 MP4 完整解码通过，导出时长与目标一致。

单元与真实媒体回归还验证重复词歧义、跨词边界、源哈希变化、保护词、完全删除、重复 ID、
未知指令、路径覆盖、不同画幅/帧率、旋转、音频延迟和累计帧舍入。

这些检查不执行真实语音识别服务，不证明人工听感、输出音频全候选反向 ASR、剪映打开兼容性或异机打开。
报告中对应的 `target_open_verified`、`full_reverse_asr_verified`、`spoken_final_acceptance` 保持 false。
